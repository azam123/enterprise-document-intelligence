# Implemented Service Code\n\nThe src tree now contains executable .NET 8 service projects rather than status-only placeholders.\n\n## Runtime flow\n\nDocumentService accepts authenticated multipart uploads, writes originals to Azure Blob Storage, persists tenant-scoped metadata in SQL Server, and publishes DocumentUploaded.\n\nIngestionService consumes the event and publishes DocumentIngestionCompleted.\n\nProcessingService normalizes content into chunks and publishes DocumentProcessed.\n\nEmbeddingService calls Azure OpenAI embeddings and publishes EmbeddingsCreated.\n\nIndexingService writes chunks/vectors to Azure AI Search.\n\nSearchService performs tenant-filtered retrieval.\n\nAgentService applies an agent budget and prompt policy, retrieves authorized context, and calls Azure OpenAI.\n\nMcpGateway exposes an explicit tool allow-list and rejects unknown/oversized tool requests.\n\nAuditService persists tenant-scoped compliance events.\n\n## Security\n\nAPIs validate Microsoft Entra bearer tokens through Microsoft.Identity.Web. Authorization uses application roles. Every SQL/search access path carries the resolved tenant ID. Service-to-service Azure SDK clients use managed identity when connection strings/API keys are absent.\n\n## Reliability\n\nService Bus processors use manual settlement, bounded concurrency, prefetch, logging, retry-by-abandon and dead-letter after five deliveries. Correlation IDs are propagated through events.\n\n## Important deployment note\n\nReplace placeholder configuration with Key Vault/managed identity references and provision the Azure AI Search index with a vector field whose dimensions match the selected embedding model before production deployment.\n
